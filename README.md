# Bank Transaction Data Analysis

## Project Overview

This project focuses on analyzing bank transaction data to identify transaction patterns, clean the dataset, and generate business insights through Exploratory Data Analysis (EDA).

## Objectives

* Analyze customer transaction behavior
* Perform data cleaning and preprocessing
* Detect and remove outliers
* Explore transaction patterns and trends
* Generate meaningful business insights

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset Summary

* Total Transactions Analyzed: 2,399
* Total Features: 16

## Data Cleaning Performed

* Checked for missing values
* Removed duplicate records
* Detected and removed outliers
* Prepared clean data for further analysis and machine learning

### Cleaning Results

* Missing Values: None Found
* Duplicate Records: Removed Successfully
* Outliers Removed: 113 Rows

## Key Insights

* Most transactions were performed through a few dominant transaction channels.
* Login attempts were predominantly 1, indicating normal and safe user behavior.
* Transaction amounts showed significant variation across customers.
* Customer ages ranged between 18 and 80 years.

## Conclusion

The dataset was successfully cleaned and analyzed. No major fraud patterns were observed in the available data. After preprocessing and outlier removal, the dataset became suitable for machine learning and predictive analytics applications.
